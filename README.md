# [Bài tập] Trang Web Tĩnh Giới Thiệu Về Sách (Bootstrap Demo)

Dự án xây dựng trang web tĩnh giới thiệu về sách hoàn chỉnh và responsive trên đa dạng kích thước màn hình theo mẫu chuẩn CodeGym.

---

## Các thành phần cấu trúc chính
1. **Header & Book Overview**: Thanh điều hướng Navbar với icon thương hiệu, phần giới thiệu tổng quan cuốn sách (tiêu đề, tác giả, tóm tắt và nút mua ngay).
2. **Author**: Phần giới thiệu tác giả cuốn sách (Mr. Devid Smith) kèm hình ảnh và tiểu sử chi tiết.
3. **Features & Numbers**: Các tính năng độc đáo của tác phẩm và khối số liệu thống kê (Happy Clients, Tickets Submitted, Total Projects).
4. **Prices**: Bảng so sánh các gói ấn bản sách (PDF, E-book, Hardcover).
5. **Download**: Phần tải xuống ứng dụng hỗ trợ đọc sách trên Desktop và Mobile.
6. **Reader’s Say**: Nhận xét và đánh giá thực tế từ độc giả (sử dụng Bootstrap Carousel và Card layout).
7. **Footer**: Thông tin liên hệ, bản quyền, đăng ký bản tin Newsletter và liên kết mạng xã hội.

---

## Công nghệ sử dụng
- HTML5 & CSS3
- Bootstrap 4.6.0
- Font Awesome 5.10.0
- jQuery 3.6.0
- Responsive Mobile Layout
